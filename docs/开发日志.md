## 2026-11-17 座右铭猫尾巴与代码配色

**总结：关于页标题只留名字，座右铭挪到页头全站显示、首页逐字打出；代码配色对齐 One Dark Pro，修掉 Highlight.js 隔行空一行；文章页灯绳换成橘猫尾巴。**

固件：不适用，主题仓库无固件，提交 3ef51ae。同批改动：首页回退与加载优化、关于页与像素点缀、工具条像素图标。

### 背景/现象

- 关于页标题「吃了没？我是南北的猫」读起来别扭。
- 首页只有头像、昵称、导航和列表，显得空。
- 用户 VSCode 用 One Dark，希望代码块配色一致。
- 灯绳是灰线吊一个空心圆，和像素风不搭，用户希望换成小猫尾巴。

### 原因分析

依据等级：实测，截图、计算样式与线上页面 HTML。

- 主题 mac-black 原本就是 Atom One Dark 系，但缺运算符、类名、基础类型等分组；注释 #5c6370 在 #282c34 上对比度约 2.5:1。
- 线上 https://haxiox.github.io/ 用 Highlight.js：每行输出 `<span class="line">…</span><br>`，主题又把 `.line` 设成块级，一行换两次，线上截图里所有代码块都隔行空一行。这是老问题，与本次配色无关。
- 线上 ESP32 那篇 15 个代码块里 14 个没写语言，输出为 plaintext，不生成任何 token，配色再改也是灰的，要在博客侧处理。

### 改动

- 关于页：删掉本批次刚加的 `about.profile.greeting`、`about.profile.motto`，标题只输出名字。
- 页头座右铭 `avatar.motto`：navigation.ejs 把每个字拆成两层 span，外层管出现动画，内层管悬浮波浪，两个动画分层，悬浮结束不会把出现动画重播一遍。所有页面都显示，页头高度一致；只有首页第 1 页带 `motto--typing`，每字间隔 120ms 弹出。配了座右铭时橘色光标从昵称挪到座右铭末尾。
- mac-block.css：按 One Dark Pro 重写 token 分组，同时覆盖 hljs 无前缀类名和 Prism 的 token 类名。隐藏 `.line + br`，空行用一个空格撑起行高。
- pixel.css：灯绳变成 4px 宽、带深色条纹的尾巴，灯泡换成 8×8 卷起的尾巴尖。收起时每 4 秒甩一下，展开时来回摇；位置、命中区、展开高度沿用 catalog-left.css。
- _config.yml、README、README-zh、CHANGELOG 同步；预览站 verify-preview.js 共 65 项。

### 方案演进

- 座右铭第一版设想只在首页显示。那样首页页头多一行，切到其他页导航会上下跳，和之前关于页「怪怪的」是同一个问题，改为全站显示、只在首页打字。
- 打字效果没有用宽度从 0 拉开的写法：中文在等宽字体里的宽度不一定是 2ch，居中文字每出一个字还会整体左移。改为逐字从隐藏到出现，字的位置从头到尾不动；代价是光标一开始就在行尾，不跟着字走。
- 第一版光标隐藏规则 `.avatar--motto .nickname a::after` 和原规则权重相同、排在前面，被覆盖，实测昵称后仍有光标，改成 `.avatar.avatar--motto`。
- `console` 在 hljs 里是 `variable language_`，第一版给了斜体，VSCode 里不是斜体，去掉。`int`、`char` 在 hljs 里是 `type`，第一版归到黄色，VSCode 里是紫色，挪到关键字组。
- 函数参数 `params` 没有标红：hljs 的 params 连括号一起包住，标红会把括号也染红。
- `#define BUF_SIZE 128` 在 hljs 里整行都是 meta，没有更细的 token，整行显示为紫色；Prism 能分出宏名和数字。

### 审查结论

- verify-preview.js 65/65，test/smoke.js Highlight 和 Prism 两种模式都通过，实测。
- 首页、归档、关于、第 2 页导航都在 y=241，换页不跳，实测。
- 首页打字：300ms 时出现 1 个字，600ms 时出现 4 个字，之后全部出现；第 2 页和其他页不带打字类，实测。
- 用 4001 端口临时服务切到 Highlight.js 模式截图，配色与行距正常，空行保留；验证完删掉临时配置和 db.json 缓存，4000 端口重新生成，实测。
- 猫尾巴收起态与展开态截图正常，实测；甩尾和摇尾动画未逐帧验证，按与其他像素动画同一写法推算。
- 关掉 pixel 后座右铭仍显示，但没有光标和动效，灯绳回到灯泡，代码配色不受影响，按选择器推算。

## 2026-11-17 工具条像素图标

**总结：工具条的回到顶部、搜索、配色切换、分享四个按钮换成 8×8 像素图标，纯 CSS 遮罩实现，跟随文字色；顺带修复首次访问浅色页面显示太阳的问题。**

固件：不适用，主题仓库无固件，提交 3ef51ae。同批改动：首页回退与加载优化、关于页与像素点缀、座右铭猫尾巴与代码配色。

### 背景/现象

像素点缀第 ④ 步。工具条四个图标还是阿里 iconfont 的线条字形，和卡片切角、小橘子不是一个风格。

### 原因分析

依据等级：实测，计算样式读数与截图。

- colorscheme.js 每次切换都把 `#theme-icon` 的 className 整个改写成 `iconfont icon-sun` 或 `iconfont icon-moon`，按类名取图就能跟着切，不用改脚本。
- backtotop.js 切显隐时把整个 className 改写成 `back-to-top` 或 `back-to-top hidden`，`tools-bar-item` 类会丢。第一版按 `.tools-bar-item > a` 匹配，实测回到顶部按钮没换上。

### 改动

- pixel.css：新增五个 8×8 像素 SVG 变量，上箭头、放大镜、月牙、太阳、分享三节点，按 2px 一格画成 16px。
- 选择器 `.tools-bar > div > a > .iconfont::before`：清掉字形，背景取 currentColor，用 mask 画图标；深浅色和悬浮色自动跟随。分享弹出的 Twitter、Facebook 品牌图标隔了一层 div，不受影响。
- colorscheme.js：初始图标改为读 `<html>` 的 color-mode，dark 显示太阳、其余显示月牙。原来读 localStorage，没存过时走了深色分支。
- 悬浮时图标跳一下，和导航小橘子同一个 pixel-hop，只在 `prefers-reduced-motion: no-preference` 下启用。
- _config.yml、README、README-zh 的 pixel 注释和 CHANGELOG 同步。
- 预览站 verify-preview.js 新增一项，共 60 项。

### 方案演进

- 原计划配色切换时给图标加一个翻转动画。切换类名触发的动画在每次页面加载时也会播一次，每次换页都翻一下太吵，改成和其他按钮一样悬浮跳一下。
- 月牙第一版是左右对称的弯弧，6 倍放大看像左尖括号，改成开口朝右上的经典月牙。
- 没有改模板换成内联 SVG：要同时改 4 个模板和 colorscheme.js，CSS 覆盖一处就够，关掉 pixel 开关也能完整回到原样。

### 审查结论

- verify-preview.js 60/60，test/smoke.js 通过，实测。
- 四个按钮计算样式均为 16×16、content 为空、mask 已生效；浅色底 #666、深色底 #c1c2c5，实测。
- 分享弹出的品牌图标仍是原字形，实测。
- 外链 iconfont 加载失败时，这四个图标不再受影响，由样式推算。
- 首次访问浅色显示月牙、切一次显示太阳、切两次回到月牙；预置 localStorage 为 dark 时打开显示太阳，为 light 时显示月牙，实测。

### 验证清单

1. 打开任意文章，向下滚动，右下角出现像素上箭头；工具条四个图标都是方块像素风。
2. 鼠标移到每个图标上，图标一格一格跳一下；系统开启减少动态效果后不跳。
3. 点配色切换，太阳和月牙随之互换，图标颜色跟着深浅变。
4. 点分享，弹出的 Twitter、Facebook 图标仍是原样。
5. 清空 localStorage 后第一次打开，浅色页面应显示月牙。

## 2026-11-17 首页回退与加载优化

**总结：撤回导航左对齐、恢复线上首页格式；去掉无用的 Raleway 字体请求，MathJax 支持按文章加载并修正配置时序，主题路径统一走 url_for 以支持子路径部署。**

固件：不适用，主题仓库无固件，提交 3ef51ae。同批改动：关于页与像素点缀、工具条像素图标、座右铭猫尾巴与代码配色。

### 背景/现象

- 本地预览首页的导航行贴左，和线上 https://haxiox.github.io/ 的居中导航不一致；首页列表也被改成标题在前、日期在后。
- 每个页面在 head 里同步请求 Google Fonts，国内常卡住首屏。
- 每篇文章都下载约 1.1MB 的 tex-chtml.js，示例 9 篇里只有 1 篇用到公式。
- 部署到子路径时，主题手写的根路径资源会 404。

### 原因分析

依据等级：实测，截图和 curl/grep 结果；时序竞争一项为文档推算，未复现。

- 首页差异来自工作区里一处未提交的 base.css 改动，不是预览出错。截图对比：HEAD d6f9415 与线上一致。
- Raleway 在 base.css 里的两处引用都已注释，字体请求纯属浪费。
- mathjax.ejs 把 async 的 MathJax 脚本写在 `MathJax = {...}` 配置之前，脚本命中缓存时可能先于配置执行，行内 `$...$` 失效。
- header、clipboard、comments、mathjax、search、navigation、footer、post 里共有十多处手写 `/css`、`/plugins`、`/search.xml` 或直接输出配置里的路径，未经过 url_for。hexo 的 css()、js() 助手本身已带 url_for，不受影响。

### 改动

- 未提交的 base.css 与 CHANGELOG 改动用 `git stash` 移走，stash 名为 `nav-left-align + home title-first (reverted 2026-11-17)`，需要时可找回。
- header.ejs：删除 Raleway 的 link。
- mathjax.ejs：配置块挪到脚本之前；新增 `mathjax.per_page`，开启后只有 front-matter 写了 `mathjax: true` 的页面加载。默认 false，行为与原来一致。post.ejs 去掉外层重复的 enable 判断。
- 路径：本地资源、search.xml、头像、favicon、导航与页脚链接统一包 url_for；导航的 data-path 同步包上，保证子路径下高亮仍能匹配 location.pathname。外链经 url_for 原样返回。
- _config.yml 增加 per_page 说明；CHANGELOG 记录 Added、Fixed、Removed 各条。
- 预览站：`_config.haxorange.yml` 打开 per_page，公式示例文章加 `mathjax: true`；verify-preview.js 新增 3 项检查，配置先于脚本、无公式文章不加载、无 Google Fonts 请求。

### 方案演进

- 首页曾考虑改成导航居中加列表两端对齐，用户确认以线上格式为准，直接回退。
- per_page 默认值没有选 true：已有站点升级后公式会静默失效，改为默认 false 保持兼容，由用户主动开启。
- jQuery 与 fancybox 全站加载约 154KB，因搜索依赖 `$.ajax`、改动面大，且已 defer 不阻塞渲染，本次不动。
- 阿里 iconfont 仍是外链同步 CSS，本地化后换图标要手动维护，本次不动。

### 审查结论

- 预览站 verify-preview.js 53/53 通过，test/smoke.js 通过，实测。
- 以 `root: /blog/` 生成站点，主题输出的路径全部带 `/blog/` 前缀；剩余 3 处未带前缀的来自 hexo-blog-encrypt 插件和文章正文，不属于主题，实测。
- per_page false 时所有 post.ejs 页面仍加载 MathJax，per_page true 时只有公式文章加载，实测。
- MathJax 缓存时序竞争未能复现，修复依据为脚本执行顺序的规范推算。

### 验证清单

1. 浏览器打开 http://localhost:4000/ ，导航居中、日期在标题前，与线上一致。
2. 打开 MathJax 公式渲染那篇，多次强制刷新和普通刷新，行内与独立公式都应渲染；DevTools Network 里能看到 tex-chtml.js。
